## 评论失败边界（2026-11-14）

`src/reviews.js` 的每页请求默认 15 秒，覆盖 fetch 与 JSON 响应体；本地 `get` 可传正数 `timeoutMs` 调整，不发送给上游。任意页的网络、解析、超时或 HTTP 错误均停止继续取评论，返回已经取得的部分，第一页失败返回空数组。商品详情采集继续，不自动重试评论请求；返回空数组不代表上游实际没有评价。
